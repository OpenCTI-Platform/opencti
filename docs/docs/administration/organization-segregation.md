# Organization segregation

!!! tip "Enterprise edition"

    Platform segregation by organization is available under the "OpenCTI Enterprise Edition" license. Please read the [dedicated page](enterprise.md) to have all the information.

Organization-based segregation lets a single OpenCTI platform serve multiple organizations, such as internal business units, external partners, ISAC members or customers, while controlling which knowledge each organization's users can see. It complements the core RBAC system of users, groups and roles: once you enable it, organizations become the primary mechanism for need-to-know access control on the platform.

The guide has three parts:

- [Part 1 — Concept, installation and RBAC setup](<Part 1 - Organization-Based Segregation Concept, Installation & RBAC Setup.md>): what segregation is, its prerequisites, where to enable it, and how to set up groups and roles for a segregated platform.
- [Part 2 — Customizing the platform as the main organization](<Part 2 - Customizing the Platform as the Main Organization.md>): the administrative levers the main organization has to shape the experience of every other organization.
- [Part 3 — How to share data with organizations](<Part 3 - How to Share Data With Organizations.md>): how sharing works in practice, and how to design reliable, automated sharing workflows with playbooks.
